## Key Patterns Discovered

- Repo-local skill здесь должен оставаться instruction-only, без лишних `README.md`, `scripts/`, `references/` и без размывания scope.
- Хороший skill для FG обязан быть Russian-first, evidence-first и явно отказываться от patching, если задача про архитектурный артефакт, а не про код.
- Для архитектурных ответов по FG правильное поведение при недостатке anchors - это `evidence gap`, а не правдоподобная догадка.
- Skill refinement в этом repo лучше делать минимальным diff, через реальный prompt-test, а не через большое теоретическое переписывание.
- Dirty worktree в этом репозитории может быть шумным и содержать много несвязанных изменений; handoff должен фиксировать именно сессионный смысл, а не blindly копировать весь `git status`.
