# Обзор директории `src` (26.10.2025)

## Общий обзор
- Клиентская часть Fingineer: одностраничное React‑приложение для поиска биржевых инструментов, показа карточки бумаги, новостей и интерактивного графика.
- Коммуникация с бэкендом гибридная: REST-запросы (`fetch`/`axios`) для основных данных и Socket.IO для стрима свечей.
- Графиковая подсистема построена вокруг `lightweight-charts`, контекста состояния (`ChartContext`) и воркера расчёта индикаторов.
- UI разбит на переиспользуемые компоненты (форма поиска, модальные окна, тулбары графика и т.д.), стилизованные через обычные CSS-файлы.

## Ключевые технологии
- React 18 (хуки, контексты), `framer-motion` для анимаций (`Results/Results.js`).
- `socket.io-client` для real-time канала; логика обёрнута в эффектах `App.js`.
- `lightweight-charts` + собственные контроллеры синхронизации (`charts/ChartSyncController.js`, `charts/Pane.jsx`).
- Воркер индикаторов (`indicators/indicators.worker.js`) + хук `useIndicatorsEngine` для SMA/EMA/RSI.
- `axios` + `lodash.debounce` в поисковых компонентах.

## Основные потоки данных

### Поиск бумага → карточка
1. `SearchForm` (`components/SearchForm.js`) или `SearchModal` (`components/SearchModal/SearchModal.js`) собирают запрос, используя дебаунс для подсказок (`hooks/useSearch.js`).
2. Переданный `setQuery` из `App.js` инициирует `fetchTickerInfo` (REST на `/api/ticker/:ticker`) и обновляет:
   - `data` — основная карточка инструмента;
   - `news`/`dividends` — списки публикаций и дивидендов;
   - `selectedDate` — дата для стартовой свечи.
3. `Results/Results.js` отображает карточку, распределяя данные между дочерними блоками (`CompanyInfo`, `Price`, `KeyMetrics`, `News`, `Dividends`, `TickerInfoPanel`).

### Поток котировок и график
1. При наличии запроса и установленного сокета `App.js` вызывается `emitChartDataRequest`, который отправляет `requestChartData` с `ticker/timeframe/interval/selectedDate`.
2. Ответы Socket.IO:
   - `initialData` → `chartData` (полный массив свечей) и снятие флага `isChartLoading`.
   - `updateData` → дозапись новых свечей.
   - `error` → сохранение ошибки для отображения под графиком.
3. `Results/Chart/Chart.js` агрегирует метаданные инструмента, нормализует числовые поля (`normalizeExchange`, `formatters`) и передаёт всё в `ChartContainer`.
4. `ChartContainer` создаёт `ChartProvider` и синхронизирует внешние пропсы с контекстом (`ChartContextSync`).
5. `ChartRenderer` решает, что показать:
   - базовый режим — `ChartCanvas` (основная реализация графика, пересчитывающая индикации через `useIndicatorsEngine`);
   - альтернативный мультипанельный режим — `charts/MultiPaneChart.jsx` (отключён по умолчанию, переключается через `USE_MULTI_PANE_CHART` в `ChartRenderer.js`).
6. `ChartCanvas` управляет экземпляром `lightweight-charts`, рисует серии (`createSeries`, `prepareData` из `utils/chartUtils.js`), обновляет тултипы и активные индикаторы, использует воркер для расчёта SMA/EMA/RSI.

### Состояния поиска и оверлеи
- `Overlay/Overlay.js` отвечает за затемнение фона и контейнер модалки. Он используется как в корневом `App.js` (фон при активном поиске), так и внутри `SearchModal`.
- В расширенном режиме графика (`isChartExpanded`) появляется `ExpandedControls`, переиспользующий `SearchForm`, `TimeframeSelector` и `IntervalSelector`.

### AI-инструменты
- `api/aiService.js` инкапсулирует REST-клиент к `/api/chat` и SSE-стрим к `/api/chat-stream`.
- `AiTestButton.jsx` и `AiStreamButton.jsx` демонстрируют синхронный и потоковый сценарии работы с AI, подмешивая результаты в основной интерфейс для отладки интеграции.

## Структура директорий

### `api/`
- `aiService.js`: функции `askAI` (обычный POST) и `streamAI` (SSE) используют базовые URL и эндпоинты из `config/api.js`.

### `charts/`
- `MultiPaneChart.jsx`, `Pane.jsx`, `ChartSyncController.js`, `SyncBus.js` — инфраструктура для нескольких панелей `lightweight-charts` с синхронизацией зума/курсорной линии.
- `series/` — фабрики серий (`candles`, `volume`, `rsi`), настраивают шкалы и расцветку для многопанельного режима.

### `components/`
- **Корневые компоненты**: `Header`, `SearchForm`, `SearchModal`, `Overlay`, `LoadingSkeleton`, `Tooltip`.
- **Результаты поиска** (`Results/`):
  - `Results.js` композирует карточку, график, новости и дивиденды.
  - Поддиректории (`CompanyInfo`, `TickerInfoPanel`, `Price`, `KeyMetrics`, `News`, `Dividends`) разбивают отображение данных.
  - Папка `Chart/` содержит поддерево для графика (контекст, тулбары, канвас, карточку тикера, тултипы, утилиты и т.д.).
- **Расширенные элементы**: `ExpandedControls` (поиск + селекторы поверх расширенного графика), `IntervalSelector`, `TimeframeSelector`, `Results/Chart/ActiveIndicators` (панель включённых индикаторов).
- **AI-дебаг**: `AiTestButton`, `AiStreamButton`.
- **Primitives**: `useDropdown.js` — универсальный хук для выпадающих меню, используется тулбарами графика.

### `config/`
- `api.js` концентрирует базовые URL/эндпоинты (Socket.IO, REST, подсказки). Значения переопределяются через переменные окружения `REACT_APP_*`.

### `constants/`
- `index.js` содержит тайминги UI, предподготовленные интервалы/таймфреймы для графика и пояснения метрик (`METRIC_EXPLANATIONS`), которые переиспользуются в `Price` и селекторах.

### `hooks/`
- `useSearch.js` — обобщённая логика поиска с подсказками, используется модалкой поиска.

### `indicators/`
- `engine.js` — чистые функции SMA/EMA/RSI, разделённые от UI.
- `indicators.worker.js` — воркер, принимающий задачи от `useIndicatorsEngine` и возвращающий расчёты, чтобы не блокировать главный поток.

### `store/`
- `useCandles.js` — готовый хук для подписки на Socket.IO поток свечей (инициирует `requestChartData`, слушает `initialData`/`updateData`). Сейчас логика стрима реализована прямо в `App.js`, но хук можно использовать для изоляции стора или переноса в zustand/mobx.

### `utils/`
- `formatters.js` — форматирование чисел, дат и объёмов для UI.
- `normalizeExchange.js` — унификация названий бирж (MOEX и т.п.) для построения тикера `EXCHANGE:SYMBOL`.

### Корневые файлы `src/`
- `App.js` — главный контейнер (стейт поиска, REST, сокет, переключение режимов графика и модалок).
- `App.css`, `index.js`, `index.css`, `serviceWorkerRegistration.js`, `reportWebVitals.js`, `setupTests.js`, `logo.svg` — стандартный каркас CRA.

## Схема взаимодействия модулей
1. **Пользователь вводит запрос** → `SearchForm`/`SearchModal` → вызывают `setQuery` из `App.js`.
2. **REST**: `fetchTickerInfo` обращается к `/api/ticker`, результат попадает в `Results`.
3. **Socket.IO**: `emitChartDataRequest` запускает стрим свечей; данные обновляют `chartData`, которое синхронизируется через `ChartContext`.
4. **График**: `ChartRenderer` → `ChartCanvas` создаёт серии и, при включённых индикаторах, отправляет задания в воркер (`useIndicatorsEngine` → `indicators/indicators.worker.js` → `indicators/engine.js` → обратно в `ChartCanvas`).
5. **UI реагирует**: селекторы (`TimeframeSelector`, `IntervalSelector`) меняют состояние, триггеря пере-запросы; `ExpandedControls` появляется в полноэкранном режиме; `Overlay` управляет задним фоном.
6. **AI кнопки**: используют `askAI`/`streamAI`, демонстрируя интеграцию с тем же `config/api.js`, что и основное приложение.

## Практические заметки
- Включение мультипанельного графика: верните `true` из `USE_MULTI_PANE_CHART` (`components/Results/Chart/ChartRenderer.js`), после чего `charts/MultiPaneChart.jsx` будет использовать свечи + объём/RSI панели.
- Добавление нового индикатора: расширьте `indicators/engine.js` и воркер, затем зарегистрируйте его в `ChartContext` (`toggleIndicator`) и визуализируйте в `ChartCanvas`.
- Для кастомизации эндпоинтов используйте `.env` с переменными `REACT_APP_SOCKET_URL`, `REACT_APP_API_URL`, `REACT_APP_SUGGESTIONS_URL`.
- Хук `useCandles` готов для вынесения логики сокета из `App.js`, если потребуется переиспользование в других компонентах или state-менеджерах.

## Изменения от 26.10.2025

- Легенда индикаторов
  - Перенесена на уровень контейнера `ChartRenderer` и теперь рендерится поверх графика в обоих режимах (обычный и expanded).
  - Компактный формат чипов: «Имя • Период», маркер цвета серии.
  - Управление видимостью (Eye/EyeOff), удаление (✕), корректная подсветка кнопки удаления даже для скрытых индикаторов.
  - Инлайн‑редактор периода с пресетами (5/9/12/14/20/21/34/50/100/200) через контекст `updateIndicator` — пересчет через web‑worker.
  - Тумблер уровней RSI 30/70 (вкл/выкл) — линии рисуются только при включении.

- Мультипанель и позиционирование легенды
  - В expanded мультипанель автоматически включается при активном `volume` либо `rsi`; нижняя панель выбирается по индикатору.
  - Легенда больше не привязана к конкретному рендереру графика (Canvas/MultiPane) и всегда находится в верхнем левом углу относительно области чарта.

- «Серая цена» и опорные уровни
  - Удален дублирующий лейбл последней цены из канваса.
  - Добавлена пунктирная линия предыдущего закрытия «Пред.» (prev close) с подписью на правой шкале.
  - Для режима baseline базовая цена выставляется с учетом prev close.

- Серии и графиковая инфраструктура
  - Свечная серия в мультипанели умеет рисовать/обновлять опорную линию «Пред.» при наличии значения.
  - `ChartCanvas` получает `prevClose` из `ChartRenderer` и управляет единственной опорной линией.

- Исправления/полировка
  - Восстановлено корректное позиционирование легенды после переноса (верхний левый угол области графика).
  - Консистентное поведение легенды при включении/выключении мультипанели.
