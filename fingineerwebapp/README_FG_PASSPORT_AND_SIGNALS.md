# Sprint 1: Паспорт инструмента и пульс (спарклайн)

## Кратко, что мы сделали
- Добавлен компонент `InstrumentPassport` (универсальная "шапка" тикера).
- Добавлен `PulseBlock` со спарклайном за последний час и дельтой `+% · 1ч`.
- Введены режимы отображения full / compact.
- В compact-режиме карточка рендерится в левой колонке expanded-графика.
- Кнопки «Сравнить» / «Новости» вынесены в нижнюю часть карточки и ужаты в сетку 1×2.
- «Сектор» и «Сессия» теперь всегда показываются (в compact-режиме без разделителя).
- Спарклайн рисуется как SVG polyline, показывает дельту и анимируется при первом появлении тикера.

## Интеграция в TickerCard
- В файле `FG2/fingineerwebapp/src/components/Results/Chart/TickerCard.js` вместо старой вёрстки паспорта теперь монтируется `<InstrumentPassport size="compact" ... />`.
- Старая верстка паспорта сохранена и закомментирована под блоком «Legacy layout preserved for rollback», чтобы обеспечить быстрый откат.

## Состояние спарклайна
- Данные пока моковые (`useSparklineData` / `useSparklineBulk`) для тикеров `DSKY`, `SBER`, `GAZP`, `LKOH`.
- Спарклайн строится на основе массива закрытий за последний час.
- Анимация выполняется ручным управлением `strokeDashoffset`/`strokeDasharray` (~1.8 s) и гарантированно запускается при монтировании нового тикера через `key={ticker}`.

## Что дальше (план на сигналы FG)
- Следующий шаг — слой сигналов (зелёные/красные стрелки над свечами на графике).
- Каждая стрелка будет сопровождаться человеческим описанием события («Подтверждение начала падающего тренда»).
- По hover показываем тултип с объяснением (DOM-оверлей над графиком, не канвас).
- Фронтовый слой планируется как отдельные компоненты (`SignalMarkersLayer`, `SignalsTooltip`).
- Источник данных — socket.io вместе со свечами либо отдельный REST (будет решено позже).

## Rollback
- Вернуть старую JSX-разметку из закомментированного блока внутри `TickerCard.js`.
- Удалить импорт `InstrumentPassport` и вызов `<InstrumentPassport ... />` из `TickerCard.js`.
- При необходимости удалить каталог `FG2/fingineerwebapp/src/components/InstrumentPassport` и хук `FG2/fingineerwebapp/src/hooks/useSparklineData.js`, если нужно полностью отключить паспорт.

## Текущие ограничения
- Спарклайн пока не синхронизирован с реальной минутной лентой с биржи; данные берём из моков.
- Цвет и дельта зависят от mock-поля `deltaPct`.
- Аватар тикера = первая буква тикера.
- Вёрстка адаптирована под ширину ~220 px левой рельсы expanded-графика.
- Дополнительная директория `src/` (вне `FG2/`) была временной и удалена после аудита.
